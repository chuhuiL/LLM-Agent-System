# TemplateAgent Guide

## Overview

The **TemplateAgent** is a universal template management system that allows you to:
- Upload custom templates with placeholders
- Store templates persistently across sessions
- Generate formatted content using your templates
- Manage multiple templates for different content types

## How It Works

1. **Upload a template** with named placeholders like `{variable_name}`
2. **Store it** with a unique name for future use
3. **Generate content** by passing data to fill the placeholders
4. Templates are **saved persistently** in the `templates/` directory

## Usage Examples

### Example 1: Weather Report Template

```
You: Upload a template named weather_report with template:
Weather in {location}, {country}:
Temperature: {temperature}°F (feels like {feels_like}°F)
Conditions: {conditions}
Humidity: {humidity}%
Wind: {wind_speed} mph
Precipitation: {precipitation} mm

Description: A detailed weather report format
```

Then generate content:
```
You: Get the weather in Buffalo and generate content from the weather_report template
```

### Example 2: Email Template

```
You: Upload a template named professional_email with template:
Subject: {subject}

Dear {recipient},

{body}

Best regards,
{sender}

Description: Professional email format
```

Generate an email:
```
You: Generate from professional_email template with data:
subject = "Meeting Update"
recipient = "Team"
body = "The meeting has been rescheduled to 3 PM"
sender = "John"
```

### Example 3: Social Media Post Template

```
You: Upload a template named tweet with template:
🚀 {topic}

{content}

#{tag1} #{tag2} #{tag3}

Description: Twitter post format
```

### Example 4: Product Description Template

```
You: Upload a template named product_desc with template:
✨ {product_name}

Price: ${price}
Rating: {rating}/5 ⭐

Description:
{description}

Features:
- {feature1}
- {feature2}
- {feature3}

Description: E-commerce product description
```

## Available Commands

### Template Management

1. **Upload a template**
   ```
   Upload a template named [name] with template: [your template string]
   ```

2. **List all templates**
   ```
   List all my templates
   Show me all available templates
   ```

3. **View a specific template**
   ```
   Show me the weather_report template
   View the professional_email template
   ```

4. **Delete a template**
   ```
   Delete the old_template
   Remove the weather_report template
   ```

5. **Update a template**
   ```
   Update the weather_report template with: [new template]
   ```

### Content Generation

**Generate content from template:**
```
Generate from [template_name] with data: [dictionary of values]
```

## Template Placeholders

Use `{variable_name}` format for placeholders:
- `{name}` - Person's name
- `{date}` - Date
- `{temperature}` - Temperature value
- `{product_name}` - Product name
- Any custom variable you define!

## Integration with Weather Tool

The agent can automatically:
1. Fetch weather data using `get_weather(location)`
2. Apply your template using `generate_from_template()`

Example workflow:
```
You: Create a weather template and show me Buffalo weather using it

Agent will:
1. Get weather data for Buffalo
2. Use your template to format the output
```

## Storage

- Templates are stored in `templates/templates.json`
- They persist across sessions
- You can backup this file to save your templates

## Tips

1. **Use descriptive names** for templates (e.g., `weather_detailed`, `email_formal`)
2. **Add descriptions** to remember what each template is for
3. **Test templates** with sample data before using them in production
4. **Keep placeholders simple** and consistent

## Advanced Usage

### Combining Multiple Templates

You can create templates for different parts of content and combine them:

```
Upload summary_header template: "📊 Summary Report - {date}"
Upload summary_body template: "Total: {total}\nAverage: {average}"
Upload summary_footer template: "Generated by {system}"
```

### Dynamic Content Types

The TemplateAgent works with any structured data:
- Weather reports
- Emails
- Social media posts
- Product descriptions
- Reports
- Notifications
- And more!

## Error Handling

If you see errors like:
- `Template 'xyz' not found` - Check spelling or list templates
- `Missing data for placeholder 'abc'` - Ensure you provide all required data
- Use `view_template_content` to see what placeholders are needed

## Best Practices

1. Start with simple templates and iterate
2. Use consistent naming conventions
3. Document your templates with good descriptions
4. Test with sample data first
5. Keep a backup of your templates directory
